# ಕಸ್ತೂರಿ ಪ್ರಮಾಣಿತ ಗ್ರಂಥಾಲಯ ಉಲ್ಲೇಖ

ಕಸ್ತೂರಿಯ ಪ್ರಮಾಣಿತ ಗ್ರಂಥಾಲಯದಲ್ಲಿ ನಾಲ್ಕು ಘಟಕಗಳಿವೆ:

| ಘಟಕ | ಆಮದು | C ಸಮಾನ | ವಿಷಯ |
|-----|-------|--------|------|
| ಐಒ | `ಆಮದು "ಐಒ";` | `<stdio.h>` | ಕಡತಗಳು, ಹರಿವುಗಳು, ರೂಪಿತ ಮುದ್ರಣ/ಓದು |
| ಸಾಮಾನ್ಯ | `ಆಮದು "ಸಾಮಾನ್ಯ";` | `<stdlib.h>`, `<time.h>` | ಸ್ಮರಣೆ, ಪರಿವರ್ತನೆ, ಯಾದೃಚ್ಛಿಕ, ಸಮಯ, ಪ್ರಕ್ರಿಯೆ |
| ಪದಗಳು | `ಆಮದು "ಪದಗಳು";` | `<string.h>`, `<ctype.h>` | ಪದ ಮತ್ತು ಅಕ್ಷರ ಕ್ರಿಯೆಗಳು, UTF-8 |
| ಗಣಿತ | `ಆಮದು "ಗಣಿತ";` | `<math.h>` | ಗಣಿತ ಕ್ರಿಯೆಗಳು |

`ಐಒ` ಘಟಕವು C ಯ `<stdio.h>` ನ **ಎಲ್ಲ** ಕ್ರಿಯೆಗಳ ಸಂಪೂರ್ಣ ಅನುಷ್ಠಾನ. ಇದು C
ಗ್ರಂಥಾಲಯದ `FILE` ಅನ್ನು ಬಳಸುವುದಿಲ್ಲ. ತನ್ನದೇ ಬಫರ್ ಸಹಿತ ಹರಿವುಗಳು, ತನ್ನದೇ `printf`
ಮತ್ತು `scanf` ಯಂತ್ರಗಳನ್ನು ಹೊಂದಿದೆ, ಮತ್ತು ನೇರವಾಗಿ ಕಾರ್ಯಾಚರಣ ವ್ಯವಸ್ಥೆಯ (Win32 / POSIX)
ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಹೀಗಾಗಿ ಎಲ್ಲ ವೇದಿಕೆಗಳಲ್ಲೂ ಒಂದೇ ರೀತಿ ವರ್ತಿಸುತ್ತದೆ ಮತ್ತು
ಕನ್ನಡ/UTF-8 ಗೆ ಪೂರ್ಣ ಬೆಂಬಲ ನೀಡುತ್ತದೆ. ಅನುಷ್ಠಾನ `runtime/` ಕೋಶದಲ್ಲಿದೆ.

ಸಂಕೇತಗಳು: ಕೆಳಗಿನ ಸಹಿಗಳಲ್ಲಿ "→ ಪ್ರಕಾರ" ಎಂದರೆ ಹಿಂದಿರುಗುವ ಪ್ರಕಾರ. **ಹೊಸ ಸ್ಮರಣೆ** ಎಂದು
ಗುರುತಿಸಿದ ಕ್ರಿಯೆಗಳು ಹೊಸದಾಗಿ ಸ್ಮರಣೆ ಪಡೆದು ಫಲಿತಾಂಶವನ್ನು ಕೊಡುತ್ತವೆ. ಬಳಕೆ
ಮುಗಿದ ಮೇಲೆ ಅದನ್ನು `ಸ್ಮರಣೆ_ಬಿಡು()` ಮೂಲಕ ಬಿಡುಗಡೆ ಮಾಡಬಹುದು.

## ೧.೩ ಕಡತಗಳ ಮೇಲಿನ ಕಾರ್ಯಾಚರಣೆಗಳು

| ಕ್ರಿಯೆ | C | ವಿವರ |
|--------|---|------|
| `ಅಳಿಸು(ಪದ ಹೆಸರು) → ಸಂಖ್ಯೆ` | `remove` | ಕಡತವನ್ನು (ಅಥವಾ ಖಾಲಿ ಕೋಶವನ್ನು) ಅಳಿಸು. ಯಶಸ್ಸಿಗೆ 0, ವಿಫಲವಾದರೆ −1 |
| `ಮರುಹೆಸರಿಸು(ಪದ ಹಳೆಯ, ಪದ ಹೊಸ) → ಸಂಖ್ಯೆ` | `rename` | ಹೆಸರು ಬದಲಿಸು (ಗುರಿ ಇದ್ದರೆ ಬದಲಾಯಿಸಲಾಗುತ್ತದೆ). 0 / −1 |
| `ತಾತ್ಕಾಲಿಕ_ಕಡತ() → ಕಡತ*` | `tmpfile` | `"w+b"` ವಿಧಾನದ ತಾತ್ಕಾಲಿಕ ಕಡತ; ಮುಚ್ಚಿದಾಗ ಅಳಿಸಲಾಗುತ್ತದೆ |
| `ತಾತ್ಕಾಲಿಕ_ಹೆಸರು(ಪದ ಸ್ಥಳ) → ಪದ` | `tmpnam` | ಬಳಕೆಯಲ್ಲಿಲ್ಲದ ಕಡತ ಹೆಸರು. `ಸ್ಥಳ` ಕನಿಷ್ಠ `ತಾತ್ಕಾಲಿಕಹೆಸರು_ಉದ್ದ` ಬೈಟ್ ಇರಬೇಕು, ಅಥವಾ `ಖಾಲಿ` (ಆಂತರಿಕ ಬಫರ್) |
| `ಕಡತ_ಇದೆಯೇ(ಪದ ಹೆಸರು) → ಸಂಖ್ಯೆ` | – | ಕಡತ/ಕೋಶ ಇದ್ದರೆ 1, ಇಲ್ಲದಿದ್ದರೆ 0 |

ಎಲ್ಲ ಕಡತ ಹೆಸರುಗಳು UTF-8. Windows ನಲ್ಲಿಯೂ ಕನ್ನಡ ಹೆಸರುಗಳು ಸರಿಯಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತವೆ.

## ೧.೪ ಕಡತ ಪ್ರವೇಶ

### `ಕಡತ_ತೆರೆ(ಪದ ಹೆಸರು, ಪದ ವಿಧಾನ) → ಕಡತ*`  (`fopen`)

ಕಡತವನ್ನು ತೆರೆಯುತ್ತದೆ. ವಿಫಲವಾದರೆ `ಖಾಲಿ` ಹಿಂದಿರುಗಿಸಿ `ದೋಷಸಂಖ್ಯೆ()` ನಿಗದಿಪಡಿಸುತ್ತದೆ.

| ವಿಧಾನ | ಅರ್ಥ |
|-------|------|
| `"r"` | ಓದಲು; ಕಡತ ಇರಬೇಕು |
| `"w"` | ಬರೆಯಲು; ಹೊಸದಾಗಿ ರಚಿಸು ಅಥವಾ ಖಾಲಿ ಮಾಡು |
| `"a"` | ಕೊನೆಗೆ ಸೇರಿಸಲು; ಇಲ್ಲದಿದ್ದರೆ ರಚಿಸು |
| `"r+"` | ಓದಲು ಮತ್ತು ಬರೆಯಲು; ಕಡತ ಇರಬೇಕು |
| `"w+"` | ಓದಲು/ಬರೆಯಲು; ರಚಿಸು ಅಥವಾ ಖಾಲಿ ಮಾಡು |
| `"a+"` | ಓದಲು ಮತ್ತು ಕೊನೆಗೆ ಸೇರಿಸಲು |
| ಜೊತೆಗೆ `b` | ದ್ವಿಮಾನ (binary) ವಿಧಾನ: `"rb"`, `"wb"`, `"r+b"`, … |
| ಜೊತೆಗೆ `t` | ಪಠ್ಯ ವಿಧಾನ (ಪೂರ್ವನಿಯೋಜಿತ) |
| ಜೊತೆಗೆ `x` | `"wx"`: ಕಡತ ಈಗಾಗಲೇ ಇದ್ದರೆ ವಿಫಲ (`ದೋಷ_ಈಗಾಗಲೇ_ಇದೆ`) |

Windows ನಲ್ಲಿ ಪಠ್ಯ ವಿಧಾನದಲ್ಲಿ `"\n"` CRLF ಆಗಿ ಬರೆಯಲ್ಪಡುತ್ತದೆ ಮತ್ತು CRLF `"\n"` ಆಗಿ
ಓದಲ್ಪಡುತ್ತದೆ. Linux/macOS ನಲ್ಲಿ ಪಠ್ಯ ಮತ್ತು ದ್ವಿಮಾನ ವಿಧಾನಗಳ ನಡುವೆ ವ್ಯತ್ಯಾಸವಿಲ್ಲ.

ಓದು/ಬರೆ ಎರಡಕ್ಕೂ ತೆರೆದ ಕಡತದಲ್ಲಿ, ಓದುವಿಕೆ ಮತ್ತು ಬರೆಯುವಿಕೆಯ ನಡುವೆ C ಯಲ್ಲಿ
`fflush`/`fseek` ಕಡ್ಡಾಯ. ಕಸ್ತೂರಿಯಲ್ಲಿ ಅದು ಅಗತ್ಯವಿಲ್ಲ, ರನ್‌ಟೈಮ್ ತಾನೇ ನಿರ್ವಹಿಸುತ್ತದೆ.

### ಇತರ ಕ್ರಿಯೆಗಳು

| ಕ್ರಿಯೆ | C | ವಿವರ |
|--------|---|------|
| `ಕಡತ_ಮರುತೆರೆ(ಪದ ಹೆಸರು, ಪದ ವಿಧಾನ, ಕಡತ* ಹರಿವು) → ಕಡತ*` | `freopen` | ಇರುವ ಹರಿವನ್ನು ಹೊಸ ಕಡತಕ್ಕೆ ಜೋಡಿಸು (ಉದಾ: `ಹೊರಹರಿವು` ಅನ್ನು ಕಡತಕ್ಕೆ ತಿರುಗಿಸಲು). `ಹೆಸರು` `ಖಾಲಿ` ಆದರೆ ವಿಧಾನ ಮಾತ್ರ ಬದಲಾಗುತ್ತದೆ |
| `ಕಡತ_ಮುಚ್ಚು(ಕಡತ* ಹರಿವು) → ಸಂಖ್ಯೆ` | `fclose` | ಬಫರ್ ಹರಿಸಿ ಮುಚ್ಚು. 0 ಅಥವಾ `ಕಡತಾಂತ` |
| `ಕಡತ_ಹರಿಸು(ಕಡತ* ಹರಿವು) → ಸಂಖ್ಯೆ` | `fflush` | ಬಫರ್‌ನಲ್ಲಿರುವುದನ್ನು ಬರೆ. `ಖಾಲಿ` ಕೊಟ್ಟರೆ ಎಲ್ಲ ಹರಿವುಗಳನ್ನೂ ಹರಿಸು |
| `ಬಫರ್_ನಿಗದಿ(ಕಡತ* ಹರಿವು, ಪದ ಬಫರ್)` | `setbuf` | `ಬಫರ್` `ಖಾಲಿ` ಆದರೆ ಬಫರ್ ಇಲ್ಲದ ಹರಿವು; ಇಲ್ಲದಿದ್ದರೆ `ಬಫರ್_ಅಳತೆ` ಗಾತ್ರದ ಬಫರ್ |
| `ಬಫರ್_ವಿಧ_ನಿಗದಿ(ಕಡತ* ಹರಿವು, ಪದ ಬಫರ್, ಸಂಖ್ಯೆ ವಿಧ, ದೀರ್ಘ ಅಳತೆ) → ಸಂಖ್ಯೆ` | `setvbuf` | `ಪೂರ್ಣ_ಬಫರ್`/`ಸಾಲು_ಬಫರ್`/`ಬಫರ್_ಇಲ್ಲ`. ಮೊದಲ I/O ಮೊದಲು ಕರೆಯಬೇಕು. 0 ಯಶಸ್ಸು |

ಪೂರ್ವನಿಯೋಜಿತ ಬಫರಿಂಗ್: ಕನ್ಸೋಲ್‌ಗೆ ಹೋಗುವ `ಹೊರಹರಿವು` ಸಾಲು ಬಫರ್, ಕಡತ/ಪೈಪ್‌ಗೆ ಹೋಗುವುದು
ಪೂರ್ಣ ಬಫರ್. `ದೋಷಹರಿವು` ಬಫರ್ ಇಲ್ಲದ್ದು. ಉಳಿದ ಕಡತಗಳು ಪೂರ್ಣ ಬಫರ್. `ಒಳಹರಿವಿ`ನಿಂದ
ಓದುವ ಮೊದಲು `ಹೊರಹರಿವು` ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಹರಿಸಲ್ಪಡುತ್ತದೆ.

## ೧.೫ ರೂಪಿತ ಹೊರಹರಿವು (printf ಕುಟುಂಬ)

| ಕ್ರಿಯೆ | C | ಎಲ್ಲಿಗೆ |
|--------|---|--------|
| `ರೂಪಮುದ್ರಣ(ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `printf` | `ಹೊರಹರಿವು` |
| `ಕಡತ_ರೂಪಮುದ್ರಣ(ಕಡತ* ಹರಿವು, ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `fprintf` | ಹರಿವು |
| `ಪದರೂಪಮುದ್ರಣ(ಪದ ಸ್ಥಳ, ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `sprintf` | ಬಫರ್ (ಗಾತ್ರ ಪರಿಶೀಲನೆ ಇಲ್ಲ) |
| `ಮಿತ_ಪದರೂಪಮುದ್ರಣ(ಪದ ಸ್ಥಳ, ದೀರ್ಘ ಅಳತೆ, ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `snprintf` | ಬಫರ್, ಗರಿಷ್ಠ `ಅಳತೆ−1` ಬೈಟ್ + ಸೊನ್ನೆ |
| `ಪದರೂಪಿಸು(ಪದ ರೂಪ, ...) → ಪದ` | `asprintf` | **ಹೊಸ ಸ್ಮರಣೆ**; ಬೇಕಾದಷ್ಟು ದೊಡ್ಡ ಪದ |
| `ಪಟ್ಟಿ_ರೂಪಮುದ್ರಣ(ಪದ ರೂಪ, ಚರಪಟ್ಟಿ ಪಟ್ಟಿ)` | `vprintf` | |
| `ಪಟ್ಟಿ_ಕಡತ_ರೂಪಮುದ್ರಣ(ಕಡತ*, ಪದ, ಚರಪಟ್ಟಿ)` | `vfprintf` | |
| `ಪಟ್ಟಿ_ಪದರೂಪಮುದ್ರಣ(ಪದ, ಪದ, ಚರಪಟ್ಟಿ)` | `vsprintf` | |
| `ಪಟ್ಟಿ_ಮಿತ_ಪದರೂಪಮುದ್ರಣ(ಪದ, ದೀರ್ಘ, ಪದ, ಚರಪಟ್ಟಿ)` | `vsnprintf` | |
| `ಪಟ್ಟಿ_ಪದರೂಪಿಸು(ಪದ ರೂಪ, ಚರಪಟ್ಟಿ) → ಪದ` | `vasprintf` | **ಹೊಸ ಸ್ಮರಣೆ** |

ಹಿಂದಿರುಗುವ ಮೌಲ್ಯ: ಬರೆದ ಬೈಟ್‌ಗಳ ಸಂಖ್ಯೆ, ದೋಷವಾದರೆ ಋಣ ಸಂಖ್ಯೆ. `ಮಿತ_ಪದರೂಪಮುದ್ರಣ`
ಸ್ಥಳ ಸಾಕಾಗಿದ್ದರೆ *ಬರೆಯಬೇಕಾಗಿದ್ದ* ಬೈಟ್‌ಗಳ ಸಂಖ್ಯೆಯನ್ನು ಕೊಡುತ್ತದೆ (C ಯಂತೆ).

### ರೂಪ ಪದದ ವಿನ್ಯಾಸ

```
%[ಧ್ವಜಗಳು][ಅಗಲ][.ನಿಖರತೆ][ಉದ್ದ]ಪರಿವರ್ತನೆ
```

**ಪರಿವರ್ತನೆಗಳು**

| ಪರಿವರ್ತನೆ | ವಾದ | ಹೊರಹರಿವು |
|-----------|-----|-----------|
| `%d`, `%i` | `ಸಂಖ್ಯೆ` | ದಶಮಾನ ಪೂರ್ಣಾಂಕ |
| `%lld` | `ದೀರ್ಘ` | ದಶಮಾನ ಪೂರ್ಣಾಂಕ |
| `%u` | `ಸಂಖ್ಯೆ` | ಚಿಹ್ನೆರಹಿತ ದಶಮಾನ |
| `%o` | ಪೂರ್ಣಾಂಕ | ಅಷ್ಟಮಾನ |
| `%x`, `%X` | ಪೂರ್ಣಾಂಕ | ಷೋಡಶಮಾನ (ಸಣ್ಣ / ದೊಡ್ಡ ಅಕ್ಷರ) |
| `%b`, `%B` | ಪೂರ್ಣಾಂಕ | **ದ್ವಿಮಾನ** (ಕಸ್ತೂರಿ ವಿಸ್ತರಣೆ); `%#b` → `0b101` |
| `%f`, `%F` | `ದಶಾಂಶ` | ಸ್ಥಿರ ಬಿಂದು, ಪೂರ್ವನಿಯೋಜಿತ 6 ದಶಮಾನ ಸ್ಥಾನ |
| `%e`, `%E` | `ದಶಾಂಶ` | ಘಾತ ರೂಪ: `1.500000e+03` |
| `%g`, `%G` | `ದಶಾಂಶ` | `%f` ಅಥವಾ `%e` ಯಲ್ಲಿ ಚಿಕ್ಕದು; ಕೊನೆಯ ಸೊನ್ನೆಗಳಿಲ್ಲ |
| `%a`, `%A` | `ದಶಾಂಶ` | ಷೋಡಶಮಾನ ದಶಾಂಶ: `0x1.8p+1` |
| `%c` | `ಅಕ್ಷರ` / `ಸಂಖ್ಯೆ` | ಒಂದು ಬೈಟ್ |
| `%lc` | `ಸಂಖ್ಯೆ` (ಯುನಿಕೋಡ್ ಸಂಕೇತ) | ಆ ಅಕ್ಷರ UTF-8 ನಲ್ಲಿ: `ರೂಪಮುದ್ರಣ("%lc", 'ಕ')` |
| `%s` | `ಪದ` | ಪದ; `ಖಾಲಿ` ಆದರೆ `(ಖಾಲಿ)` |
| `%p` | ಸೂಚಕ | `0x…` |
| `%n` | `ಸಂಖ್ಯೆ*` | ಇಲ್ಲಿಯವರೆಗೆ ಬರೆದ ಬೈಟ್‌ಗಳ ಸಂಖ್ಯೆಯನ್ನು ಸಂಗ್ರಹಿಸು |
| `%%` | – | `%` |

**ಧ್ವಜಗಳು**

| ಧ್ವಜ | ಅರ್ಥ |
|------|------|
| `-` | ಎಡಕ್ಕೆ ಹೊಂದಿಸು |
| `+` | ಧನ ಸಂಖ್ಯೆಗಳಿಗೂ ಚಿಹ್ನೆ |
| ` ` (ಅಂತರ) | ಧನ ಸಂಖ್ಯೆಗಳ ಮುಂದೆ ಅಂತರ |
| `#` | ಪರ್ಯಾಯ ರೂಪ: `0x`, `0b`, `0` ಪೂರ್ವಪ್ರತ್ಯಯ; `%g` ಯಲ್ಲಿ ಸೊನ್ನೆಗಳನ್ನು ಉಳಿಸು |
| `0` | ಅಗಲವನ್ನು ಸೊನ್ನೆಗಳಿಂದ ತುಂಬು |
| `~` | **ಕನ್ನಡ ಅಂಕಿಗಳು** (ಕಸ್ತೂರಿ ವಿಸ್ತರಣೆ): `%d %i %u %f %e %g` ಗಳಿಗೆ |
| `'` | ಸ್ವೀಕರಿಸಲಾಗುತ್ತದೆ, ಆದರೆ ಯಾವ ಪರಿಣಾಮವೂ ಇಲ್ಲ |

**ಅಗಲ ಮತ್ತು ನಿಖರತೆ:** ಸಂಖ್ಯೆಯಾಗಿ ಅಥವಾ `*` ಆಗಿ (ಮುಂದಿನ `ಸಂಖ್ಯೆ` ವಾದದಿಂದ) ಕೊಡಬಹುದು.
`%s` ಮತ್ತು `%c` ಗಳಲ್ಲಿ **ಅಗಲ ಮತ್ತು ನಿಖರತೆಯನ್ನು ಅಕ್ಷರಗಳಲ್ಲಿ (ಯುನಿಕೋಡ್ ಸಂಕೇತಗಳಲ್ಲಿ)
ಎಣಿಸಲಾಗುತ್ತದೆ, ಬೈಟ್‌ಗಳಲ್ಲಿ ಅಲ್ಲ.** ಆದ್ದರಿಂದ ಕನ್ನಡ ಕೋಷ್ಟಕಗಳು ಸರಿಯಾಗಿ ಹೊಂದುತ್ತವೆ, ಮತ್ತು
`%.3s` UTF-8 ಅನುಕ್ರಮವನ್ನು ಮಧ್ಯದಲ್ಲಿ ಕತ್ತರಿಸುವುದಿಲ್ಲ.

**ಉದ್ದ ಸೂಚಕಗಳು:** `hh`, `h`, `l`, `ll`, `q`, `j`, `z`, `t`, `L` (C ಯಂತೆ).

> **ಗಮನಿಸಿ:** ಕಸ್ತೂರಿಯ `ದೀರ್ಘ` C ಯ `long long`. ಆದ್ದರಿಂದ ಅದಕ್ಕೆ **`%lld`** ಬಳಸಿ, `%ld`
> ಅಲ್ಲ (Windows ನಲ್ಲಿ `long` 32 ಬಿಟ್). `ಗಾತ್ರ(...)` ಮತ್ತು `ಉದ್ದ(...)` ಕೂಡ `ದೀರ್ಘ`
> ಕೊಡುತ್ತವೆ. `ತಾರ್ಕಿಕ` ಮತ್ತು `ಅಕ್ಷರ` ವಾದಗಳು `ಸಂಖ್ಯೆ` ಆಗಿ ಹೋಗುತ್ತವೆ (`%d`, `%c`).
> ರೂಪ ಮತ್ತು ವಾದಗಳ ಪ್ರಕಾರಗಳು ಹೊಂದುತ್ತವೆಯೇ ಎಂಬುದನ್ನು ಸಂಕಲಕ ಪರಿಶೀಲಿಸುವುದಿಲ್ಲ.

ದಶಾಂಶ ಪರಿವರ್ತನೆ ನಿಖರ: ಪ್ರತಿ ಮೌಲ್ಯವೂ ಸರಿಯಾಗಿ ದುಂಡಾಗುತ್ತದೆ (ಸಮ ಅಂಕಿಯ ಕಡೆಗೆ,
half-to-even). `inf`, `nan` ಗಳನ್ನು ಬೆಂಬಲಿಸಲಾಗುತ್ತದೆ. ಹೀಗಾಗಿ ಎಲ್ಲ ವೇದಿಕೆಗಳಲ್ಲೂ ಫಲಿತಾಂಶ
ಒಂದೇ.

**ಉದಾಹರಣೆಗಳು**

```
ರೂಪಮುದ್ರಣ("[%5d] [%-5d] [%05d]\n", 42, 42, 42);   // [   42] [42   ] [00042]
ರೂಪಮುದ್ರಣ("%~d\n", 2024);                         // ೨೦೨೪
ರೂಪಮುದ್ರಣ("%.3f %~.2f\n", 3.14159, 3.14159);       // 3.142 ೩.೧೪
ರೂಪಮುದ್ರಣ("%e %g\n", 1500.0, 0.0001);             // 1.500000e+03 0.0001
ರೂಪಮುದ್ರಣ("%#x %#o %#b\n", 255, 8, 5);            // 0xff 010 0b101
ರೂಪಮುದ್ರಣ("[%-8s|%8s]\n", "ಕನ್ನಡ", "abc");        // [ಕನ್ನಡ   |     abc]
ರೂಪಮುದ್ರಣ("%lc%lc\n", 'ಓ', 'ಂ');                  // ಓಂ
ರೂಪಮುದ್ರಣ("%*d|%.*f\n", 6, 7, 2, 2.5);            // "     7|2.50"
ರೂಪಮುದ್ರಣ("%lld\n", ಗಾತ್ರ(ದಶಾಂಶ));                // 8

ಪದ ಸಂದೇಶ = ಪದರೂಪಿಸು("%s ಅವರಿಗೆ %d ಅಂಕ", "ರಾಮ", 95);
ಕಡತ_ರೂಪಮುದ್ರಣ(ದೋಷಹರಿವು, "ಎಚ್ಚರಿಕೆ: %s\n", ಸಂದೇಶ);
ಸ್ಮರಣೆ_ಬಿಡು(ಸಂದೇಶ);
```

(`ಕನ್ನಡ` ಐದು ಸಂಕೇತಗಳು - ಕ, ನ, ್, ನ, ಡ - ಆದ್ದರಿಂದ ಮೂರು ಅಂತರಗಳು ಸೇರುತ್ತವೆ.)

## ೧.೬ ರೂಪಿತ ಒಳಹರಿವು (scanf ಕುಟುಂಬ)

| ಕ್ರಿಯೆ | C | ಮೂಲ |
|--------|---|-----|
| `ರೂಪಓದು(ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `scanf` | `ಒಳಹರಿವು` |
| `ಕಡತ_ರೂಪಓದು(ಕಡತ* ಹರಿವು, ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `fscanf` | ಹರಿವು |
| `ಪದರೂಪಓದು(ಪದ ಮೂಲ, ಪದ ರೂಪ, ...) → ಸಂಖ್ಯೆ` | `sscanf` | ಪದ |
| `ಪಟ್ಟಿ_ರೂಪಓದು`, `ಪಟ್ಟಿ_ಕಡತ_ರೂಪಓದು`, `ಪಟ್ಟಿ_ಪದರೂಪಓದು` | `vscanf`, `vfscanf`, `vsscanf` | `ಚರಪಟ್ಟಿ` ರೂಪಗಳು |

ಹಿಂದಿರುಗುವ ಮೌಲ್ಯ: ಯಶಸ್ವಿಯಾಗಿ ನಿಯೋಜಿಸಿದ ಮೌಲ್ಯಗಳ ಸಂಖ್ಯೆ. ಯಾವುದೇ ಪರಿವರ್ತನೆಗೆ ಮೊದಲೇ
ಒಳಹರಿವು ಮುಗಿದರೆ `ಕಡತಾಂತ` (−1).

ವಾದಗಳು ಚರಗಳ **ವಿಳಾಸಗಳು** (`&ಚರ`) ಆಗಿರಬೇಕು. `ಅಕ್ಷರ` ಸರಣಿಗೆ `&` ಬೇಕಿಲ್ಲ.

| ಪರಿವರ್ತನೆ | ವಾದ | ಓದುವಿಕೆ |
|-----------|-----|---------|
| `%d` | `ಸಂಖ್ಯೆ*` | ದಶಮಾನ ಪೂರ್ಣಾಂಕ |
| `%lld` | `ದೀರ್ಘ*` | ದಶಮಾನ ಪೂರ್ಣಾಂಕ |
| `%i` | `ಸಂಖ್ಯೆ*` | ಪೂರ್ವಪ್ರತ್ಯಯದಿಂದ ಆಧಾರ: `0x1F`, `0b101`, `017` (ಅಷ್ಟಮಾನ), ದಶಮಾನ |
| `%u`, `%o`, `%x`, `%b` | `ಸಂಖ್ಯೆ*` | ಚಿಹ್ನೆರಹಿತ / ಅಷ್ಟಮಾನ / ಷೋಡಶಮಾನ / ದ್ವಿಮಾನ |
| `%lf` | `ದಶಾಂಶ*` | ದಶಾಂಶ ಸಂಖ್ಯೆ (`inf`, `nan`, ಷೋಡಶಮಾನ ದಶಾಂಶಗಳೂ ಸೇರಿ) |
| `%c` | `ಅಕ್ಷರ*` | ಒಂದು ಬೈಟ್ (ಖಾಲಿಜಾಗ ಬಿಡುವುದಿಲ್ಲ; `" %c"` ಬಳಸಿ ಬಿಡಬಹುದು); `%5c` → 5 ಬೈಟ್‌ಗಳು |
| `%lc` | `ಸಂಖ್ಯೆ*` | ಒಂದು UTF-8 ಅಕ್ಷರದ ಯುನಿಕೋಡ್ ಸಂಕೇತ |
| `%s` | `ಅಕ್ಷರ` ಸರಣಿ | ಖಾಲಿಜಾಗದವರೆಗಿನ ಪದ |
| `%[...]`, `%[^...]` | `ಅಕ್ಷರ` ಸರಣಿ | ಗುಂಪಿನಲ್ಲಿರುವ / ಇಲ್ಲದ ಬೈಟ್‌ಗಳು: `%[^\n]` = ಸಾಲಿನ ಉಳಿದ ಭಾಗ |
| `%p` | `ಶೂನ್ಯ**` | ಸೂಚಕ |
| `%n` | `ಸಂಖ್ಯೆ*` | ಇಲ್ಲಿಯವರೆಗೆ ಓದಿದ ಬೈಟ್‌ಗಳು |
| `%*d` ಇತ್ಯಾದಿ | – | ಓದಿ, ನಿಯೋಜಿಸದೆ ಬಿಡು |

> **ಗಮನಿಸಿ:** `ದಶಾಂಶ` ಕ್ಕೆ **`%lf`** ಬಳಸಿ. C ಯಂತೆ, ಉದ್ದ ಸೂಚಕವಿಲ್ಲದ `%f`/`%e`/`%g`
> 4-ಬೈಟ್ `float` ಅನ್ನು ಬರೆಯುತ್ತವೆ, ಆದರೆ ಕಸ್ತೂರಿಯಲ್ಲಿ ಆ ಪ್ರಕಾರವಿಲ್ಲ. `ದೀರ್ಘ` ಕ್ಕೆ `%lld` ಬಳಸಿ.

ಕಸ್ತೂರಿ ವಿಸ್ತರಣೆಗಳು:

* **ಎಲ್ಲ ಸಂಖ್ಯಾ ಪರಿವರ್ತನೆಗಳು ಕನ್ನಡ ಅಂಕಿಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತವೆ:** `೪೨`, `೩.೧೪`, `-೭`.
* `%s`/`%[` ಗಳ ಅಗಲ ಬೈಟ್‌ಗಳಲ್ಲಿದೆ (ಬಫರ್ ಗಾತ್ರಕ್ಕೆ ಹೊಂದುವಂತೆ). ಆದರೆ UTF-8 ಅಕ್ಷರವನ್ನು
  ಮಧ್ಯದಲ್ಲಿ ಕತ್ತರಿಸುವುದಿಲ್ಲ; ಉಳಿದ ಬೈಟ್‌ಗಳು ಮುಂದಿನ ಓದಿಗೆ ಉಳಿಯುತ್ತವೆ.
* `%b` ದ್ವಿಮಾನ, `%lc` ಯುನಿಕೋಡ್ ಸಂಕೇತ.

```
ಸಂಖ್ಯೆ ದಿನ, ತಿಂಗಳು, ವರ್ಷ;
(ಪದರೂಪಓದು("೧೫-೦೮-೧೯೪೭", "%d-%d-%d", &ದಿನ, &ತಿಂಗಳು, &ವರ್ಷ) == 3) ಆದರೆ
    ರೂಪಮುದ್ರಣ("%d/%d/%d\n", ದಿನ, ತಿಂಗಳು, ವರ್ಷ);           // 15/8/1947

ಅಕ್ಷರ ಹೆಸರು[64];
ದಶಾಂಶ ಎತ್ತರ;
ರೂಪಓದು("%63s %lf", ಹೆಸರು, &ಎತ್ತರ);
```

## ೧.೭ ಅಕ್ಷರ ಮತ್ತು ಸಾಲು ಒಳಹರಿವು / ಹೊರಹರಿವು

| ಕ್ರಿಯೆ | C | ವಿವರ |
|--------|---|------|
| `ಕಡತ_ಅಕ್ಷರಪಡೆ(ಕಡತ* ಹ) → ಸಂಖ್ಯೆ` | `fgetc` | ಮುಂದಿನ ಬೈಟ್ (0–255) ಅಥವಾ `ಕಡತಾಂತ` |
| `ಹರಿವು_ಅಕ್ಷರಪಡೆ(ಕಡತ* ಹ) → ಸಂಖ್ಯೆ` | `getc` | ಮೇಲಿನದಕ್ಕೆ ಸಮಾನ |
| `ಅಕ್ಷರಪಡೆ() → ಸಂಖ್ಯೆ` | `getchar` | `ಒಳಹರಿವಿ`ನಿಂದ |
| `ಕಡತ_ಸಾಲುಪಡೆ(ಪದ ಸ್ಥಳ, ಸಂಖ್ಯೆ ಮಿತಿ, ಕಡತ* ಹ) → ಪದ` | `fgets` | ಗರಿಷ್ಠ `ಮಿತಿ−1` ಬೈಟ್ ಅಥವಾ `\n` ಸೇರಿ ಸಾಲು. ಕಡತಾಂತದಲ್ಲಿ `ಖಾಲಿ` |
| `ಸಾಲುಪಡೆ(ಪದ ಸ್ಥಳ, ದೀರ್ಘ ಮಿತಿ) → ಪದ` | `gets_s` | `ಒಳಹರಿವಿ`ನಿಂದ ಒಂದು ಸಾಲು, `\n` ಇಲ್ಲದೆ; ಉದ್ದವಾದ ಭಾಗ ಬಿಡಲ್ಪಡುತ್ತದೆ |

| ಕ್ರಿಯೆ | C | ವಿವರ |
|--------|---|------|
| `ಯಾದೃಚ್ಛಿಕ() → ಸಂಖ್ಯೆ` | `rand` | 0 … `ಯಾದೃಚ್ಛಿಕ_ಗರಿಷ್ಠ` |
| `ಯಾದೃಚ್ಛಿಕ_ಬೀಜ(ದೀರ್ಘ ಬೀಜ)` | `srand` | ಅನುಕ್ರಮದ ಆರಂಭ ಬಿಂದು. ಸಾಮಾನ್ಯವಾಗಿ `ಯಾದೃಚ್ಛಿಕ_ಬೀಜ(ಪ್ರಸ್ತುತ_ಸಮಯ())` |
| `ಯಾದೃಚ್ಛಿಕ_ವ್ಯಾಪ್ತಿ(ಸಂಖ್ಯೆ ಕೆಳ, ಸಂಖ್ಯೆ ಮೇಲ್) → ಸಂಖ್ಯೆ` | – | `ಕೆಳ` … `ಮೇಲ್` (ಎರಡೂ ಸೇರಿ) |
| `ಯಾದೃಚ್ಛಿಕ_ದಶಾಂಶ() → ದಶಾಂಶ` | – | 0.0 ≤ x < 1.0 |

ಜನಕ (xorshift) ಎಲ್ಲ ವೇದಿಕೆಗಳಲ್ಲೂ ಒಂದೇ. ಆದ್ದರಿಂದ ಒಂದೇ ಬೀಜ ಎಲ್ಲೆಡೆ ಒಂದೇ ಅನುಕ್ರಮವನ್ನು
ಕೊಡುತ್ತದೆ. ಇದು ಗೂಢಲಿಪಿ (cryptography) ಬಳಕೆಗೆ ಸೂಕ್ತವಲ್ಲ.

## ೨.೭ ಸಮಯ

| ಕ್ರಿಯೆ | C | ವಿವರ |
|--------|---|------|
| `ಪ್ರಸ್ತುತ_ಸಮಯ() → ದೀರ್ಘ` | `time(NULL)` | 1970-01-01 ರಿಂದ ಸೆಕೆಂಡುಗಳು |
| `ಗಡಿಯಾರ() → ದಶಾಂಶ` | `clock()/CLOCKS_PER_SEC` | ಪ್ರೋಗ್ರಾಂ ಬಳಸಿದ ಸಂಸ್ಕರಣಾ ಸಮಯ, ಸೆಕೆಂಡುಗಳಲ್ಲಿ |

## ೨.೮ ವಿಂಗಡಣೆ ಮತ್ತು ಹುಡುಕಾಟ (ಕಸ್ತೂರಿಯಲ್ಲೇ ಬರೆದವು)

| ಕ್ರಿಯೆ | ವಿವರ |
|--------|------|
| `ಸಂಖ್ಯೆಗಳನ್ನು_ವಿಂಗಡಿಸು(ಸಂಖ್ಯೆ* ಸರಣಿ, ಸಂಖ್ಯೆ ಪರಿಮಾಣ)` | ಏರಿಕೆ ಕ್ರಮದಲ್ಲಿ ವಿಂಗಡಿಸು (insertion sort) |
| `ದ್ವಿಮಾನ_ಹುಡುಕು(ಸಂಖ್ಯೆ* ಸರಣಿ, ಸಂಖ್ಯೆ ಪರಿಮಾಣ, ಸಂಖ್ಯೆ ಗುರಿ) → ಸಂಖ್ಯೆ` | ವಿಂಗಡಿಸಿದ ಸರಣಿಯಲ್ಲಿ ಗುರಿಯ ಸೂಚ್ಯಂಕ, ಇಲ್ಲದಿದ್ದರೆ −1 |

C ಯ `qsort`/`bsearch` ಕ್ರಿಯಾ ಸೂಚಕಗಳನ್ನು ಬಯಸುತ್ತವೆ. ಕಸ್ತೂರಿಯಲ್ಲಿ ಕ್ರಿಯಾ ಸೂಚಕಗಳಿಲ್ಲದ
ಕಾರಣ ಬದಲಿಗೆ ಈ ಕ್ರಿಯೆಗಳನ್ನು ಒದಗಿಸಲಾಗಿದೆ. ಇತರ ಪ್ರಕಾರಗಳಿಗೆ ಇವುಗಳ ಮಾದರಿಯಲ್ಲಿ ನಿಮ್ಮದೇ
ಕ್ರಿಯೆಗಳನ್ನು ಬರೆಯಬಹುದು (`lib/ಸಾಮಾನ್ಯ.kst` ನೋಡಿ).

# ಭಾಗ ೩: ಪದಗಳು (ಪದ ಮತ್ತು ಅಕ್ಷರ ಕ್ರಿಯೆಗಳು)

ಉದ್ದಗಳು ಮತ್ತು ಸ್ಥಾನಗಳು **ಬೈಟ್‌ಗಳಲ್ಲಿ**. ಆದರೆ ಹೆಸರಿನಲ್ಲಿ "ಅಕ್ಷರ" ಇರುವ UTF-8 ಕ್ರಿಯೆಗಳು
(`ಅಕ್ಷರಗಳ_ಸಂಖ್ಯೆ`, `ಉಪಪದ`, `ಅಕ್ಷರ_ಸಂಕೇತ`, `ಪದ_ತಿರುಗಿಸು`) ಯುನಿಕೋಡ್ ಸಂಕೇತಗಳಲ್ಲಿ
ಎಣಿಸುತ್ತವೆ.

## ೩.೧ ಮೂಲ ಪದ ಕ್ರಿಯೆಗಳು (`<string.h>`)

| `ಉಪಪದ_ಹುಡುಕು(ಪದ ಪ, ಪದ ಉಪ) → ಪದ` | `strstr` | ಉಪಪದದ ಮೊದಲ ಸ್ಥಳ ಅಥವಾ `ಖಾಲಿ` |
| `ಪದ_ಪ್ರತಿ(ಪದ ಪ) → ಪದ` | `strdup` | **ಹೊಸ ಸ್ಮರಣೆ** |

## ೩.೨ ಹೆಚ್ಚುವರಿ ಪದ ಕ್ರಿಯೆಗಳು

| ಕ್ರಿಯೆ | ವಿವರ | ಉದಾಹರಣೆ |
|--------|------|---------|
| `ಸ್ಥಾನ_ಹುಡುಕು(ಪದ ಪ, ಪದ ಉಪ) → ದೀರ್ಘ` | ಉಪಪದದ ಬೈಟ್ ಸ್ಥಾನ, ಇಲ್ಲದಿದ್ದರೆ −1 | `ಸ್ಥಾನ_ಹುಡುಕು("abcabc", "ca")` → 2 |
| `ಪದ_ಸಮಾನವೇ(ಪದ ಅ, ಪದ ಬ) → ತಾರ್ಕಿಕ` | ವಿಷಯ ಸಮವೇ (`ಅ == ಬ` ಕ್ಕೆ ಸಮಾನ) | |
| `ಆರಂಭವಾಗುತ್ತದೆಯೇ(ಪದ ಪ, ಪದ ಪೂರ್ವ) → ತಾರ್ಕಿಕ` | | `ಆರಂಭವಾಗುತ್ತದೆಯೇ("ಕನ್ನಡ", "ಕ")` → ಸತ್ಯ |
| `ಕೊನೆಗೊಳ್ಳುತ್ತದೆಯೇ(ಪದ ಪ, ಪದ ಉತ್ತರ) → ತಾರ್ಕಿಕ` | | `ಕೊನೆಗೊಳ್ಳುತ್ತದೆಯೇ("ಪಾಠ.kst", ".kst")` → ಸತ್ಯ |
| `ಪದ_ಸೇರಿಸು(ಪದ ಅ, ಪದ ಬ) → ಪದ` | ಎರಡನ್ನೂ ಸೇರಿಸಿದ ಹೊಸ ಪದ; **ಹೊಸ ಸ್ಮರಣೆ** | `("ಕನ್ನಡ", " ನಾಡು")` → `"ಕನ್ನಡ ನಾಡು"` |
| `ಅಕ್ಷರಗಳ_ಸಂಖ್ಯೆ(ಪದ ಪ) → ದೀರ್ಘ` | ಯುನಿಕೋಡ್ ಸಂಕೇತಗಳ ಸಂಖ್ಯೆ | `"ಕನ್ನಡ"` → 5 |
| `ಉಪಪದ(ಪದ ಪ, ದೀರ್ಘ ಆರಂಭ, ದೀರ್ಘ ಸಂಖ್ಯೆಗಳು) → ಪದ` | ಸಂಕೇತ ಸ್ಥಾನ `ಆರಂಭ` ದಿಂದ `ಸಂಖ್ಯೆಗಳು` ಸಂಕೇತಗಳು (ಋಣವಾದರೆ ಕೊನೆಯವರೆಗೆ); **ಹೊಸ ಸ್ಮರಣೆ** | `("ಕನ್ನಡ", 0, 2)` → `"ಕನ"` |
| `ಅಕ್ಷರ_ಸಂಕೇತ(ಪದ ಪ, ದೀರ್ಘ ಸ್ಥಾನ) → ಸಂಖ್ಯೆ` | ಸ್ಥಾನದಲ್ಲಿರುವ ಸಂಕೇತ, ಹೊರಗಿದ್ದರೆ −1 | `("ಕನ್ನಡ", 1)` → 0x0CA8 (ನ) |
| `ಪದ_ತಿರುಗಿಸು(ಪದ ಪ) → ಪದ` | ಸಂಕೇತಗಳನ್ನು ಹಿಮ್ಮುಖ ಕ್ರಮದಲ್ಲಿ; **ಹೊಸ ಸ್ಮರಣೆ** | `"abc"` → `"cba"` |
| `ದೊಡ್ಡಕ್ಷರ_ಪದ(ಪದ ಪ) → ಪದ` | ASCII ಸಣ್ಣಕ್ಷರಗಳನ್ನು ದೊಡ್ಡದಾಗಿ; **ಹೊಸ ಸ್ಮರಣೆ** | `"Kasturi"` → `"KASTURI"` |
| `ಸಣ್ಣಕ್ಷರ_ಪದ(ಪದ ಪ) → ಪದ` | ASCII ದೊಡ್ಡಕ್ಷರಗಳನ್ನು ಸಣ್ಣದಾಗಿ; **ಹೊಸ ಸ್ಮರಣೆ** | |
| `ಪದ_ಕತ್ತರಿಸು(ಪದ ಪ) → ಪದ` | ಎರಡೂ ಕೊನೆಗಳ ಖಾಲಿಜಾಗ ತೆಗೆ; **ಹೊಸ ಸ್ಮರಣೆ** | `"  ನಮಸ್ತೆ \n"` → `"ನಮಸ್ತೆ"` |
| `ಪದ_ಪುನರಾವರ್ತಿಸು(ಪದ ಪ, ಸಂಖ್ಯೆ ಬಾರಿ) → ಪದ` | **ಹೊಸ ಸ್ಮರಣೆ** | `("-", 5)` → `"-----"` |
| `ಪದ_ಬದಲಿಸು(ಪದ ಪ, ಪದ ಹಳೆಯ, ಪದ ಹೊಸ) → ಪದ` | ಎಲ್ಲ ಸ್ಥಳಗಳಲ್ಲಿ ಬದಲಿಸು; **ಹೊಸ ಸ್ಮರಣೆ** | `("ಅ-ಬ-ಕ", "-", ", ")` → `"ಅ, ಬ, ಕ"` |

ಕನ್ನಡದಲ್ಲಿ ಒಂದು "ಅಕ್ಷರ" (ಉದಾ: `ಕ್ಷ`, `ನ್ನ`) ಹಲವು ಯುನಿಕೋಡ್ ಸಂಕೇತಗಳಿಂದ (ವ್ಯಂಜನ + `್` +
ವ್ಯಂಜನ) ಆಗಿರಬಹುದು. ಮೇಲಿನ ಕ್ರಿಯೆಗಳು ಸಂಕೇತಗಳನ್ನು ಎಣಿಸುತ್ತವೆ. ಆದ್ದರಿಂದ ಸ್ವರ ಚಿಹ್ನೆ ಅಥವಾ
ವಿರಾಮದ ಮಧ್ಯದಲ್ಲಿ ಕತ್ತರಿಸಿದರೆ ಅಕ್ಷರ ಬೇರ್ಪಡಬಹುದು.

## ೩.೩ ಅಕ್ಷರ ವರ್ಗೀಕರಣ (`<ctype.h>`)

ಇವು ASCII ಬೈಟ್‌ಗಳ ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತವೆ (`ಅಕ್ಷರ` ಅಥವಾ `ಕಡತ_ಅಕ್ಷರಪಡೆ` ಫಲಿತಾಂಶ). ಫಲಿತಾಂಶ
`ತಾರ್ಕಿಕ`. ಕನ್ನಡ ಅಕ್ಷರಗಳಿಗೆ ಮುಂದಿನ ವಿಭಾಗದ ಕ್ರಿಯೆಗಳನ್ನು ಬಳಸಿ.

| ಕ್ರಿಯೆ | C | ಸತ್ಯವಾಗುವುದು |
|--------|---|---------------|
| `ಅಂಕಿಯೇ(ಅ)` | `isdigit` | `0`–`9` |
| `ವರ್ಣವೇ(ಅ)` | `isalpha` | `a`–`z`, `A`–`Z` |

| `ದೊಡ್ಡಕ್ಷರವೇ(ಅ)` | `isupper` | `A`–`Z` |
| `ಸಣ್ಣಕ್ಷರವೇ(ಅ)` | `islower` | `a`–`z` |
| `ಷೋಡಶಾಂಕಿಯೇ(ಅ)` | `isxdigit` | `0`–`9`, `a`–`f`, `A`–`F` |
| `ವಿರಾಮಚಿಹ್ನೆಯೇ(ಅ)` | `ispunct` | ಮುದ್ರಣೀಯ, ಅಕ್ಷರ/ಅಂಕಿ/ಅಂತರವಲ್ಲದ್ದು |
| `ನಿಯಂತ್ರಣವೇ(ಅ)` | `iscntrl` | 0–31, 127 |
| `ಮುದ್ರಣೀಯವೇ(ಅ)` | `isprint` | 32–126 |
| `ದೊಡ್ಡಕ್ಷರಕ್ಕೆ(ಅ) → ಸಂಖ್ಯೆ` | `toupper` | `'a'` → `'A'` |
| `ಸಣ್ಣಕ್ಷರಕ್ಕೆ(ಅ) → ಸಂಖ್ಯೆ` | `tolower` | `'A'` → `'a'` |

## ೩.೪ ಕನ್ನಡ ಸಹಾಯಕ ಕ್ರಿಯೆಗಳು (ಯುನಿಕೋಡ್ ಸಂಕೇತಗಳ ಮೇಲೆ)

